Ces exercices se font en équipe de 2 ou 3 personnes avec votre compte Microsoft 365 du Cégep Marie-Victorin. Assurez-vous d'être connectés avant de commencer.

**Durée estimée :** 1 h 30 à 2 h  
**Prérequis :** Compte Microsoft 365 actif (courriel @cegepmv.ca ou équivalent)

---

## Exercice 1 — Partager un fichier avec un coéquipier

OneDrive est l'espace de stockage en nuage de Microsoft 365. Cet exercice vous apprend à y déposer un fichier et à le partager avec quelqu'un d'autre sans envoyer de pièce jointe.

**Étapes :**

1. Ouvrez [OneDrive du Collègue](https://collegemv-my.sharepoint.com/) et connectez-vous avec votre compte du Cégep.
2. Cliquez sur **+ Nouveau** → **Document Word** pour créer un nouveau fichier. Nommez-le `Atelier-M365-[votre prénom]`.
3. Ajoutez quelques lignes de texte dans le document (votre nom, le nom du cours, la date).
4. Revenez à OneDrive (flèche retour ou onglet). Localisez votre fichier dans la liste.
5. Faites un clic droit sur le fichier → **Partager**.
6. Dans la fenêtre de partage, entrez l'adresse courriel de votre coéquipier.
7. Choisissez le niveau d'accès **Peut modifier** et ajoutez un message, puis cliquez sur **Envoyer**.

{{< notice style="tip" title="Conseil" >}}
Vous pouvez aussi copier le lien de partage avec **Copier le lien** et le coller dans un message Teams ou un courriel Outlook. Choisissez alors **Personnes spécifiques** pour limiter l'accès à votre équipe.
{{< /notice >}}

**À observer :** Votre coéquipier reçoit-il une notification? Peut-il ouvrir et modifier le document depuis son compte?

**À livrer :** Capturez l'écran montrant le fichier partagé dans OneDrive avec le nom du coéquipier visible dans les accès.

## Exercice 2 — Créer et co-éditer un classeur Excel

Excel en ligne permet à plusieurs personnes de modifier un même classeur simultanément, en temps réel, depuis n'importe quel navigateur.

**Étapes :**

1. Dans OneDrive, cliquez sur **+ Nouveau** → **Classeur Excel**. Nommez-le `Budget-Equipe-[votre prénom]`.
2. Créez un tableau simple avec les colonnes suivantes :

   | Poste de dépense | Montant prévu | Montant réel | Différence |
   |-----------------|--------------|-------------|-----------|
   | Matériel | | | |
   | Logiciels | | | |
   | Formation | | | |

3. Remplissez la colonne **Montant prévu** avec des valeurs fictives.
4. Partagez le classeur avec votre coéquipier (comme à l'exercice 1, avec accès **Peut modifier**).
5. Demandez à votre coéquipier de remplir la colonne **Montant réel** pendant que vous observez les modifications apparaître en direct.
6. Dans la colonne **Différence**, entrez la formule `=C2-B2` (Montant réel − Montant prévu) et appliquez-la à toutes les lignes.
7. Observez le curseur de votre coéquipier qui s'affiche dans une couleur différente.

{{< notice style="info" title="À noter" >}}
L'historique des versions est automatiquement conservé. Cliquez sur **Fichier** → **Historique des versions** pour voir toutes les modifications avec l'heure et l'auteur de chaque changement.
{{< /notice >}}

**À livrer :** Capturez l'écran montrant les deux curseurs actifs dans le classeur (le vôtre et celui de votre coéquipier).

## Exercice 3 — Partager le lien dans Teams et Outlook

Microsoft Teams et Outlook s'intègrent directement à OneDrive et SharePoint. Cet exercice vous apprend à partager un lien de document dans les deux canaux de communication principaux de M365.

**Partie A — Partager dans Teams**

1. Ouvrez [teams.microsoft.com](https://teams.microsoft.com) et rejoignez (ou créez) un canal avec votre équipe.
2. Dans la zone de message en bas, cliquez sur l'icône **Joindre** (trombone 📎) → **OneDrive**.
3. Naviguez jusqu'au classeur Excel créé à l'exercice 2 et sélectionnez-le.
4. Rédigez un message d'accompagnement, par exemple : *«Voici notre classeur de budget partagé. Merci de compléter votre colonne.»*
5. Appuyez sur **Envoyer**. Le fichier apparaît dans le fil de discussion avec un aperçu.
6. Cliquez sur le fichier depuis Teams : il s'ouvre directement dans Teams sans quitter l'application.

**Partie B — Partager dans Outlook**

1. Ouvrez [outlook.office.com](https://outlook.office.com) et composez un nouveau courriel.
2. Ajoutez l'adresse de votre coéquipier comme destinataire.
3. Dans la barre d'outils du message, cliquez sur l'icône **Joindre** → **OneDrive**.
4. Sélectionnez votre document Word de l'exercice 1.
5. Outlook vous propose de partager un **lien** (recommandé) plutôt que de joindre une copie — choisissez **Partager en tant que lien OneDrive**.
6. Envoyez le courriel.

{{< notice style="warning" title="Lien vs pièce jointe" >}}
Partager un **lien** OneDrive plutôt qu'une pièce jointe présente plusieurs avantages : tout le monde travaille sur **la même version**, les modifications sont visibles en temps réel, et il n'y a pas de fichiers dupliqués qui traînent dans les boîtes courriel.
{{< /notice >}}

**À livrer :** Capturez l'écran du message Teams avec le fichier joint et le courriel Outlook envoyé avec le lien OneDrive.

## Exercice 4 — Co-rédiger un document Word avec commentaires et suggestions

Word en ligne offre deux modes de collaboration avancée : les **commentaires** (pour poser des questions ou faire des remarques) et le mode **Suivi des modifications** (pour proposer des changements que l'auteur peut accepter ou refuser). Ces fonctions reproduisent le circuit de révision utilisé dans la plupart des entreprises et institutions.

**Étapes :**

1. Ouvrez le document Word créé à l'exercice 1 dans Word en ligne.
2. **Auteur (vous) :** Rédigez un court texte de 3 à 5 phrases décrivant ce qu'est Microsoft 365 (en vos propres mots).
3. **Réviseur (votre coéquipier) :** Active le mode **Suivi des modifications** via **Révision** → **Suivi des modifications**.
4. Le réviseur apporte 2 ou 3 corrections ou reformulations dans le texte. Les modifications apparaissent en couleur avec le nom de l'auteur.
5. Le réviseur ajoute au moins un **commentaire** : sélectionnez un mot ou une phrase, puis cliquez sur **Révision** → **Nouveau commentaire** et posez une question ou suggère une amélioration.
6. **Auteur (vous) :** Passez en revue les modifications proposées dans le volet droit. Pour chaque modification :
   - Cliquez sur ✓ pour **Accepter**
   - Cliquez sur ✗ pour **Refuser**
7. Répondez aux commentaires de votre coéquipier avec la fonction **Répondre** dans le fil de commentaire, puis marquez-les comme **Résolus**.

{{< notice style="tip" title="Conseil" >}}
Le volet **Commentaires** (icône de bulle en haut à droite) affiche tous les commentaires du document en un seul endroit. C'est pratique pour passer rapidement d'un commentaire à l'autre sans faire défiler le document.
{{< /notice >}}

**À livrer :** Capturez l'écran montrant le document avec au moins une modification suivie et un commentaire visibles simultanément.
