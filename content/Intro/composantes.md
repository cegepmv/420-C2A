## Client Web

Votre ordinateur (cellulaire, tablette, etc.) agit comme un **client** faisant une **demande** sur le Web. Il joue le rôle d'intermédiare entre vous et le **serveur web** avec l'aide de ses logiciels de navigateur (Chrome, Firefox, Edge, Safari) et son système d'exploitation (Windows 11, MacOs, Android, iOS). Ce dernier lui permet d'**afficher le contenu** sur votre écran et d'acheminer les **demandes** via son lien **réseau** (Wifi, filaire). Son interface avec nous peut varier selon le dispositif (clavier, souris, micro pour la voie, écran tactile, manette, etc.).

## Serveur Web

Sur chaque site web consulté, le contenu nous est transmis à partir d'un réseau de plusieurs machines ou serveurs qui se trouvent sur le réseau Internet. Ils sont situés partout à travers le monde et ils se comportent comme des facteurs qui transfèrent les informations à l'adresse d'un autre serveur ou d'un client. À chaque fois que vous vous connectez sur un serveur, vous créez une **requête (une demande)** à l'adresse IP où se trouve celui-ci. Il vous **répond** en fonction de la requête reçue avec le contenu et le code de réponse (**HTTP 200 OK** ou **HTTP 404 adresse introuvable**). En réalité, il existe plusieurs code HTTP de réponse.

### Modèle OSI

Le modèle OSI est un cadre théorique de référence en sept couches qui explique comment un navigateur web communique avec un serveur à travers Internet.

Référence: https://www.cloudflare.com/learning/ddos/glossary/open-systems-interconnection-model-osi/

## Hébergement

Pour avoir un serveur sur le net. Il faut trouver un fournisseur de service qui offre l'hébergement web. Il en existe une quantité énorme de nos jours. La plupart des entreprises oeuvrant dans la création de site web, offre ce service pour une somme assez petite ou gratuitement si vous acceptez certaine contrainte (espace limité pour votre site web, publicités ajoutés, etc.). Par exemple, sur **Wix**, vous pouvez utilisez leur nom de domaine (ajouté avec un préfix) en échange de **publicité** pour les clients qui se connectent sur votre site web. En d'autres mots, ils **restent propriétaires de votre site web à 100%** et ils font la promotion de leur entreprise via votre petite vitrine web fait avec leurs outils!

## Nom de domaine

Pour que vos client vous trouvent sur le net, il vous fait une adresse URL (Uniform Resource Locator) avec un nom de domaine par exemple (cegepmv.ca). Votre fournisseur de dns vous permettra de pointer sur le serveur de votre choix (votre adresse IP sur le net).
