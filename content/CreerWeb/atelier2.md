## Wix.com

### 1 - Créer un compte
Commencez **gratuitement**. Pour se faire, utilisez votre compte Google, Facebook, Apple ou avec un **courriel** (rectangle **vert**).
![Étape 1](/images/wix-etape1.png)


### 2 - Créér un site web
Les nouveaux CMS votre proposent de commencer avec une idée et ils génèrent une structure avec l'IA déjà toute construite pour vous. Vous pouvez **passer** (rectange **vert**) pour poursuivre sans l'aide le l'IA.
![Étape 2](/images/wix-etape2.png)

### 3 - Choix du type de site web
Choisissez une caractéristique (Portefolio, Blog, Restaurant, etc.) et cliquez sur **Continue**. Il est également possible de passer en cliquant sur **Skip**.
![Étape 3](/images/wix-etape3.png)

### 4 - Passer à Modifier le site
On ne va pas compléter les informations tout de suite. Passons à l'étape **Modifier le site**.
![Étape 4](/images/wix-etape4.png)

### 5 - Choisissez un gabarit
Maintenant que votre site web doit être créé, vous devez le décrire à l'IA de Wix ou choisir un gabarit. Pour mon portfolio, je vais prendre un gabarit en cliquant sur **modifier**.
![Étape 5](/images/wix-etape5.png)

Wix va maintenant prendre un certain temps avant de vous permettre la modification du site web.

### 6 - Mode édition
Beaucoup d'éléments se présentent à vous et il faut y aller graduellement. Pour changer de page, cliquez sur page (rectangle vert).

![Étape 6](/images/wix-etape6.png)

Pour voir toutes les pages, cliquez sur **Gérer les pages**
![Étape 6a](/images/wix-etape6a.png)

Choisissez une des pages, cliquez sur **Modifier la page**
![Étape 6b](/images/wix-etape6b.png)
