## Se connecter à Google Ads

Une campagne est considérée un projet de publicité pour une application dans le langage Google Ads. Pour se faire, vous devez entrer un mode de paiement et choisir votre contenu de publicité. Mais avant d'aller plus loin. Nous allons créer un compte Google Ads et associer un mode de paiement.

- Entrez l'adresse suivante dans votre navigateur: https://business.google.com/

- Cliquez sur **Se Connecter**.

- Activez votre compte en suivant les étapes et acceptez les conditions d'utilisation.
![](/images/googleads-11.png)

- Vous devez ajouter votre monde de paiement pour avoir accès à une campagne.
![](/images/googleads-8.png)

- Entrez votre mode de paiement.
![](/images/googleads-9.png)

- Validez bien que votre méthode paiement est acceptée.
![](/images/googleads-10.png)

## Créer une campagne Google Ads

- Connectez-vous sur https://ads.google.com/ et cliquez sur **Se Connecter**.

- Assurez-vous que votre compte est actif en allant voir vos **préférences**.
![](/images/googleads-13.png)

- Cliquez sur **Nouvelle Campagne**.
![](/images/googleads-12.png)

- Choisissez votre objectif. (J'ai choisi: **Trafic vers le site Web**)
![](/images/googleads-14.png)

- Choisissez un type de campagne. (J'ai choisi: **Réseau de Recheche**)
![](/images/googleads-15.png)

- Donnez un nom à votre campagne. (J'ai choisi: **DemoContenuWeb**)

- Entrez le nom de votre site web. Cliquez sur **Continuer**.
![](/images/googleads-16.png)

- Sélectionner votre objectif de conversion. Je vais alors cliquez sur **Configurer**.
![](/images/googleads-17.png)

- Choisissez **Configurer manuellement**. Nous allons calculer notre objectif plus tard via un petit script.
![](/images/googleads-18.png)

- Cliquez suir **Accepter et continuer.**
![](/images/googleads-19.png)

### Enchères
Vous êtes habituellement en compétition avec d'autres vendeurs d'annonces. Google calcule les règles d'affichage de votre annonce en fonction de votre budget, vos objectifs, votre publique cible, etc.

- Faites un choix sur ce que vous privilégier. J'ai choisi **Maximiser les conversions**.
![](/images/googleads-20.png)

- Cliquez ensuite sur **Suivant**.

- Faitez vos choix pour les régions, langues. (Je choisi Canada et français comme langue).
![](/images/googleads-21.png)

- Rafinez votre recherche avec des segments d'audience selon votre page web.
![](/images/googleads-22.png)

- Cliquez sur **Suivant**.

- J'ai fait le choix ici d'exclure les campagne avecv AI MAX pour exclure les recherches liées aux résultats pour AI.
![](/images/googleads-23.png)

- Cliquez sur **Suivant**.

### Génération de mots clés et de composants
Selon le contenu de votre page web. Google Ads peut vous proposez quels mots clés seront utilisés pour votre campagne.
![](/images/googleads-24.png)

- Révisez le résultat affiché et visionnez votre annonce en prévisionnement.
![](/images/googleads-25.png)

- Améliorer votre annonce en appliquant les suggestions affichées selon votre contexte de publicité (mots clés, lien connexe, etc.).
![](/images/googleads-26.png)

- Cliquez sur **Suivant** quand vous êtes prêt(e).

### Budget de votre campagne
Maintenant que votre annonce est prête, choisissez votre budget.
![](/images/googleads-27.png)

### Confirmation
- Votre campagne est prête à être publier. 
![](/images/googleads-28.png)

- Attendez quelques instants et cliquez sur **Publier la campagne**.
![](/images/googleads-29.png)

### Calcul de conversion
Pour savoir si vous avez réussi votre campagne, Google Ads calcul la conversion. Donc, si mon objectif était que les clients de mon site web cliquent sur Abonnez-vous. Je dois ajouter le bout de code après ce clic.
